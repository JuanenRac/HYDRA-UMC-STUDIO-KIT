## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

This package keeps the sign-in tokens of the web clients and sends them to a server. If you discover a vulnerability affecting **where a token is stored**, **to whom it is sent**, **how a launch address is cleaned** or **how an error message can leak a credential**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe whether the bug lets a page, another origin or a log read a token, or sends a request to an address the caller did not configure.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy before anything is made public.
